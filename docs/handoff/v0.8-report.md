# v0.8 — Base selection UX + real weightings (2026-10-04)

## Create New Item

Base selector in steps (`BaseSelector.tsx`, `lib/base-navigation.ts`, `craft-db/src/catalog.ts`):
item type → kind (only where there is a choice) → base, sorted by level. Breadcrumb, Back and
Escape go one level up; each level keeps its scroll position; "Search all bases…" lists only
player-facing bases with their place ("Body Armours · STR/INT"); every list has its own search and
level/name sort. Research: `docs/research/base-selection-ux.md`.

- Step 1 sections: **Armour** (Body Armours, Boots, Gloves, Helmets), **Jewellery** (Amulets, Belts,
  Rings), **Weapons** (One-handed, Two-handed), **Off-hand** (Bucklers, Foci, Quivers, Shields).
  Category from the class category and base tags (hand tags; slot tags for body armour slots).
- Armour kinds: defence properties (Armour = STR, Evasion = DEX, Energy Shield = INT) checked against
  the `*_armour` spawn tag; both agree → STR, DEX, INT, STR/DEX, STR/INT, DEX/INT, STR/DEX/INT; one
  missing → the other; disagreement (variant bases such as Grasping Mail) → **Special**.
- Weapons: step 2 lists real PoE 2 classes of the dataset (one-handed: Daggers, Flails, One Hand
  Axes/Maces/Swords, Sceptres, Spears, Wands; two-handed: Bows, Crossbows, Quarterstaves, Staves,
  Talismans, Two Hand Axes/Maces/Swords). Jewellery, Foci, Quivers skip step 2.
- Catalog: RePoE `base_items.json` 5 496 records (all classes) → 1 841 equipment base records in the
  dataset → 1 343 player-facing → 1 304 offered (39 more are player-facing but in classes the engine
  does not craft: jewels, flasks, charms). Hidden: 51 `[DNT]` (dev marker), 262 unique-only records
  (`…Unique…` export id), 185 not in the official trade base list. Raw data keeps everything; Ctrl+V
  import still recognises hidden records.

## Weights

- Source: PoE2DB item class / attribute pages (`ModsView` JSON), weights by Krakenbul (Prohibited
  Library, recombinators). Provenance `poe2db-weightings`, method `recombinator-observation`,
  confidence `community`. Snapshot 2026-10-03, PoE2DB patch 0.5.5 = dataset 0.5.5.
- Pipeline: `data:weights:fetch` → `:normalize` → `:validate` → `:report` (`pnpm data:weights`).
  Research: `docs/research/poe2db-weightings.md`; model: ADR 012.
- Mapping: side + required level + affix name, then rolled numbers, spawn tags, collision groups;
  text never the key. 7 760 rows, 7 755 matched, 5 unresolved (mana-flask rows absent from our
  export), 0 ambiguous, 0 conflicts.
- Tables: 53 (one per page). 6 434 weights for 1 319 explicit modifiers; 1 321 rows "not measured"
  (PoE2DB `1`/`0`) stay unknown. 1 819 bases have a table; 14 have none (STR/DEX/INT boots, gloves,
  helmets; unique-only Golden bases).
- Craftable bases (1 559): fully weighted pools 1 180, partial 274, none 105.
  Fully weighted groups: Belts, Body Armour STR / DEX / STR-DEX, Boots, Gloves, Helmets (all attribute
  kinds with pages), Shields, Foci, Spears, Quarterstaves, Staves, Wands, Sceptres, Talismans,
  One/Two Hand Maces. Partial: Rings and Amulets (Cast Speed), Body Armour INT / STR-INT / DEX-INT
  (ES Recharge), Bows and Crossbows (level-65 Leech), Quivers (Surpassing Arrow), one STR/DEX buckler.
  Unweighted: Daggers, Flails, One/Two Hand Swords and Axes, Body Armour STR/DEX/INT.
- Golden cases (ilvl 82): Akoyan Spear, Rusted Cuirass, Rawhide Boots — fully weighted; Recurve Bow
  (2 unknown), Topaz Ring (5), Amber Amulet (6) — partial. Totals and unknown lists are pinned and
  read independently from the raw pages. Cross-check: `docs/research/weight-golden-cross-check.md`.

## Crafting

- Weighted on real data when the pool is fully known: Exalted, Transmutation, Augmentation, Regal,
  Alchemy, Chaos (remove + weighted add); Omens restrict the pool before the denominator.
- Blocked with "partial weight data" when any candidate weight is unknown (e.g. Exalted on rings with
  a free suffix; Sinistral Exaltation on the same ring works — prefixes are fully weighted).
- Annulment, Divine, Fracturing unchanged; regression tests pass.
- No equal / average / neighbouring-tier weights anywhere; `probability` → `indeterminate:
  partial-weights` instead of the former "upper bound".
- One lookup (`CraftDbView.weightFor`) → `PoolEntry.weight` used by probability, explorer and sampler;
  test `preview probability and the sampler use the same pool`.

## Known limits

- PoE2DB weights are community measurements; PoE2DB's page format is not an API and may change.
- Unmeasured families block random crafts on those bases (rings, amulets, bows, crossbows, INT body
  armours, quivers) and whole classes (daggers, flails, swords, axes).
- Multi-add / compound actions (Alchemy, Chaos, Greater Exaltation) execute but have no analytical
  probability yet (`compound-action`).
- Desecrated, essence and other layers are not weighted.

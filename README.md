# PoE 2 Craft Planner

Планировщик крафта для **Path of Exile 2**: импортируйте предмет из игры (Ctrl+V) или соберите его
из базы, задайте цель, кликайте валютой по предмету и смотрите пул модов, шанс цели, потраченное и
ожидаемую стоимость — с объяснением каждого числа. Интерфейс EN / RU.

**Сайт:** https://quroroyr.github.io/poe2-craft/

## Данные

- **Игра 0.5.5** — экспорт клиента (RePoE, клиент 4.5.5.2) и официальный список трейда: классы, базы,
  моды, тиры, группы, расходники.
- **Веса модов** — данные сообщества с PoE2DB (Krakenbul / Prohibited Library, рекомбинаторы),
  снимок 2026-10-03 для патча 0.5.5. Не из клиента игры. Если вес хоть одного кандидата неизвестен,
  шанс не считается и бросок отказывает — числа не придумываются.
- **Цены** — poe.ninja (публичный economy API). На сайте — снимок на момент сборки; цены можно
  поправить вручную.

Подробности: [источники данных](docs/data-sources.md), [веса — ADR 012](docs/adr/012-weight-tables.md).

## Что умеет

- **Создать предмет** — база в 2–3 шага: тип (броня, бижутерия, оружие, вторая рука) → вид (СИЛ,
  СИЛ/ИНТ… или класс оружия) → база. Только базы, которые есть в игре.
- **Импорт** — Ctrl+V в любом месте страницы, превью перед началом.
- **Крафт кликом** — сфера (и Omen) в руке, клик по текущему предмету. Работают Exalted,
  Transmutation, Augmentation, Regal, Alchemy, Chaos, Annulment, Divine, Fracturing Orb и 8 Omen.
- **Цель** — требования «тир N или лучше»; шанс шага, ожидаемое число попыток и стоимость.
- **Пул модов** — тиры для конкретной базы, веса, доли, причины исключения.
- **История** — undo / redo, откат к шагу, ручные правки отдельно от крафта, учёт потраченного.

Где у PoE2DB нет замеров (Cast Speed на бижутерии, ES Recharge на INT-броне, высокие тиры Leech на
луках и арбалетах, кинжалы, цепы, мечи и топоры), случайные добавления недоступны.

## Запуск

Node.js ≥ 23 и pnpm 10.

```bash
pnpm install
pnpm data:art     # картинки предметов (не хранятся в git)
pnpm dev          # http://localhost:3000
```

Production-сервер: `pnpm build && pnpm start`. Сайт на GitHub Pages собирается
[workflow](.github/workflows/pages.yml) статически при каждом пуше в `main`.

## Обновление данных после патча

```bash
pnpm data:refresh   # клиент → нормализация → веса PoE2DB → проверки → отчёт покрытия
pnpm data:art       # картинки новых баз
pnpm check          # тесты, типы, сборка
```

Покрытие весов по группам баз — `data/coverage-report.json`.

## Проверки

```bash
pnpm test        # vitest
pnpm typecheck   # tsc по пакетам и сайту
pnpm check       # всё сразу + сборка
```

## Структура

```
apps/web                    сайт Next.js (отображение и композиция)
packages/craft-domain       типы и чистые правила домена
packages/craft-db           версионная база игровых данных, веса, каталог баз
packages/item-parser        текст предмета → ItemState
packages/probability-engine пул модов, вероятности, объяснение
packages/economy            стоимость попытки и этапа
packages/craft-session      применение действий, сессия, сравнение с целью
scripts/data                конвейер данных (fetch / normalize / weights / report)
docs/                       архитектура, инварианты, источники, ADR
```

Подробнее: [архитектура](docs/architecture.md), [инварианты крафта](docs/crafting-invariants.md),
[AGENTS.md](AGENTS.md).

# PoE 2 Craft Planner

Веб-сервис для крафта в **Path of Exile 2**. Рабочий стол крафта: вставляете исходный предмет и
пример желаемого результата (Ctrl+C из игры), выбираете способ крафта, применяете шаги к текущему
предмету и видите пул модов, шанс цели, потраченное и ожидаемую стоимость с объяснением каждого числа.

> **Демо-данные и демо-симуляция.** Тиры, уровни и веса модов в CraftDB придуманы для проверки
> движка (см. [docs/data-sources.md](docs/data-sources.md)). Кнопка «Применить» разыгрывает
> упрощённую модель, а не реальную механику PoE 2. Реальны только названия баз, валют, Omen,
> тексты статов и иконки: они сверены с официальными данными трейда PoE 2.

## Запуск

Нужны Node.js ≥ 20 и pnpm 10 (`npm i -g pnpm`).

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

Production:

```bash
pnpm build
pnpm start
```

## Проверки

```bash
pnpm test         # unit-тесты всех пакетов + архитектурные (vitest)
pnpm typecheck    # tsc по каждому пакету и сайту
pnpm build        # production-сборка Next.js
pnpm check        # всё сразу
```

## Рабочий стол (v0.2)

| Блок | Что это |
|---|---|
| **Исходный предмет** (слева) | база, с которой начинаем. Вставляется из игры и разбирается парсером |
| **Текущий предмет** (центр) | то, что крафтится сейчас. До первого шага совпадает с исходным, после «Применить» меняется. Новые моды подсвечены, моды целевого предмета отмечены |
| **Целевой предмет** (справа) | пример желаемого результата. На каждом моде видно: есть / не хватает / тир хуже |
| **Способы крафта** | цель шага (недостающие моды целевого предмета или каталог), действие, версия игры; заготовки будущих механик |
| **Затраты** | **факт** — потрачено в сессии; **оценки** — цена попытки, шанс, ожидаемая стоимость этапа, разброс; редактор расходников и цен |
| **История сессии** | шаги: действие, иконки расходников, выпавший мод, его шанс, стоимость |
| **Текущий vs целевой** | `совпало / всего`, недостающие, худшие тиры, лишние моды |
| **Пул модов** | вкладки «Префиксы» / «Суффиксы», группы и тиры: вес, ilvl, уровень мода, доля, статус и причина |
| **Вероятность, «Почему так», «Данные»** | подробности расчёта из v0.1 |

**Craft session** — состояние рабочего стола: исходный, текущий и целевой предмет, история шагов,
seed симуляции. Живёт в браузере, без сервера. Отмена шага возвращает предыдущий предмет и
вычитает его стоимость; «К исходному» начинает сессию заново.

### Какие действия можно применять

Все действия — демо-модель «добавить один мод, выбранный по весу из доступного пула»:

- Add random modifier (модель Exalted Orb);
- Add random suffix / Add random prefix (ограничение стороны, как у Omen; сам Omen не симулируется);
- Add random modifier с уровнем мода ≥ 50 (модель Perfect Exalted Orb; порог взят из fixture).

Невозможное действие (нет слотов, не та редкость, неизвестный вес) честно отказывает: предмет и
затраты не меняются. Essences, Chaos / Annulment, Omen как отдельный слой, Desecration и Fracturing
показаны как «скоро» и не симулируются. Окаменелостей нет: в официальных данных трейда PoE 2 такой
категории валюты нет.

### Ограничения

- Все числа модов — fixture; одна база (Akoyan Spear) и две версии (0.4.0, 0.5.0).
- Ожидаемая стоимость этапа считается в модели «повторять из текущего состояния». Реальный
  предмет после неудачной попытки меняется, поэтому это оценка шага, а не маршрута.
- Маршрут до целевого предмета не строится (солвера пока нет).
- Сессия не сохраняется между перезагрузками страницы.

## Структура

```
apps/web                    сайт Next.js (только отображение и композиция)
packages/craft-domain       типы и чистые правила домена
packages/craft-db           версионная база игровых данных + fixture
packages/item-parser        текст предмета → ItemState
packages/probability-engine пул модов, обозреватель пула, вероятности, объяснение
packages/economy            стоимость попытки и этапа
packages/craft-session      демо-применение действий, сессия, сравнение с целью
docs/                       архитектура, модель, инварианты, источники, ADR 001–005
tests/                      архитектурные проверки и проверка иконок
```

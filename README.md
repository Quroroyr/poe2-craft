# PoE 2 Craft Planner

**Открыть сайт:** https://quroroyr.github.io/poe2-craft/

Планировщик крафта для Path of Exile 2. Вставляете предмет из игры или собираете его из базы,
задаёте цель и крафтите прямо на странице: берёте сферу, кликаете по предмету — и видите, что
выпало, сколько потрачено, какой шанс у следующего шага и сколько примерно стоит дойти до цели.

## Что умеет

- **Импорт из игры**: Ctrl+C на предмете в игре, Ctrl+V на странице — превью и старт крафта.
- **Создание предмета**: база в 2–3 шага — тип (броня, бижутерия, оружие, вторая рука) → вид
  (СИЛ, СИЛ/ИНТ… или класс оружия) → база. Только базы, которые реально есть в игре.
- **Крафт кликом**: Exalted, Transmutation, Augmentation, Regal, Alchemy, Chaos, Annulment, Divine,
  Fracturing Orb и 8 Omen. Полоса «Применимые» показывает то, что сейчас можно применить.
- **Цель**: требования «тир N или лучше»; шанс шага, ожидаемое число попыток и стоимость в div.
- **Пул модов**: все моды базы с тирами, весами, долями и причиной, почему мод сейчас недоступен.
- **История**: отмена и повтор, откат к любому шагу, ручные правки отдельно от крафта, учёт трат.
- **Объяснение**: откуда взялось каждое число — веса, знаменатель, источник данных.
- Интерфейс на английском и русском.

Где сообщество ещё не измерило веса (Cast Speed на кольцах и амулетах, ES Recharge на INT-броне,
верхние тиры Leech на луках и арбалетах, кинжалы, цепы, мечи, топоры), случайные добавления
недоступны: сайт честно пишет «веса известны частично», а не выдумывает проценты.

## Управление

| Действие | Как |
|---|---|
| Импортировать предмет | Ctrl+V в любом месте страницы |
| Взять сферу / Omen | клик по плитке в «Инструментах крафта» |
| Применить | клик по текущему предмету |
| Отменить / повторить шаг | Ctrl+Z / Ctrl+Shift+Z |
| Меню мода (в цель, заменить, fractured) | правая кнопка или «…» у мода |
| Шаг назад в выборе базы | «Назад», крошки или Esc |

## Как сделано

- **Next.js 16 + React 19**, TypeScript. Вся игровая логика — в отдельных пакетах без React
  (`packages/*`): данные, разбор текста предмета, пул модов и вероятности, экономика, сессия крафта.
- **Данные игры 0.5.5** — экспорт клиента (RePoE) и официальный список трейда GGG: базы, моды, тиры,
  группы, расходники. Тир считается для конкретной базы.
- **Веса модов** — данные сообщества с PoE2DB (Krakenbul / Prohibited Library, рекомбинаторы),
  импортируются скриптом и сопоставляются с модами без угадывания. Это не данные клиента игры.
- **Цены** — poe.ninja; на сайте — снимок на момент сборки, цену любой сферы можно поправить вручную.
- Сайт статический: собирается GitHub Actions при каждом пуше и раз в сутки (свежие цены).
- 380+ тестов, включая эталонные предметы, сверенные с независимыми источниками.

## Запуск у себя

Нужны [Node.js](https://nodejs.org/) 23 или новее и pnpm (`npm i -g pnpm`).

```
git clone https://github.com/Quroroyr/poe2-craft.git
cd poe2-craft
pnpm install
pnpm data:art
pnpm dev
```

Откроется на http://localhost:3000. Картинки предметов скачиваются командой `pnpm data:art`
(в репозитории их нет). Обновить данные после патча игры — `pnpm data:refresh`, проверить всё —
`pnpm check`.

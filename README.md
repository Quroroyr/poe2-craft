# PoE 2 Craft Planner

Веб-сервис для крафта в **Path of Exile 2**. Вставляете предмет (Ctrl+C из игры), выбираете
цель, получаете пул модов, шанс одной попытки, ожидаемое число попыток, разброс и стоимость
этапа с объяснением каждого числа.

> **v0.1 работает на демо-данных.** Тиры, уровни и веса модов в CraftDB придуманы для проверки
> движка (см. [docs/data-sources.md](docs/data-sources.md)). Реальны только названия баз, валют,
> Omen и их иконки — сверены с официальными данными трейда PoE 2.

## Запуск

Нужны Node.js ≥ 20 и pnpm 10 (`npm i -g pnpm`).

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

Production:

```bash
pnpm build
pnpm start
```

## Проверки

```bash
pnpm test         # unit-тесты всех пакетов + архитектурные (vitest)
pnpm typecheck    # tsc по каждому пакету и сайту
pnpm build        # production-сборка Next.js
pnpm check        # всё сразу
```

## Что умеет v0.1

1. Разбор текста предмета (Ctrl+C и Ctrl+Alt+C): база, редкость, ilvl, явные моды,
   fractured, нераспознанные строки (не теряются, видны пользователю).
2. Нормализованный `ItemState` с префиксами/суффиксами и debug-видом.
3. Версионная CraftDB (fixture Akoyan Spear, версии 0.4.0 и 0.5.0).
4. Выбор цели и действия (добавить мод / только суффикс / только префикс / мод уровня ≥ 50).
5. Пул модов: каждый мод версии с весом и причинами исключения.
6. Шанс `P = вес цели / вес пула`, `1/P`, шанс за 1/10/25/50/100 попыток, квантили 50/75/90/95%.
7. Экономика: редактируемые расходники и цены, стоимость попытки, ожидаемая стоимость этапа,
   квантили стоимости.
8. «Почему так»: пошаговое объяснение, источники данных и достоверность.

## Структура

```
apps/web                    сайт Next.js (только отображение и композиция)
packages/craft-domain       типы и чистые правила домена
packages/craft-db           версионная база игровых данных + fixture
packages/item-parser        текст предмета → ItemState
packages/probability-engine пул модов, вероятности, объяснение
packages/economy            стоимость попытки и этапа
docs/                       архитектура, модель, инварианты, источники, ADR
tests/                      архитектурные проверки и проверка иконок
```

# PoE 2 Craft Planner

Веб-сервис для крафта в **Path of Exile 2**. Вставьте предмет из игры (Ctrl+V в любом месте страницы)
или соберите его из базы, задайте цель, берите валюту и кликайте ею по текущему предмету — и видите пул
модов, шанс цели, потраченное и ожидаемую стоимость с объяснением каждого числа. Интерфейс — EN (по
умолчанию) или RU, переключатель в шапке.

> **Real data 0.5.5 по умолчанию (v0.8).** Закреплённый RePoE export (1841 запись баз, 3281 мод в
> слотах, 499 расходников) + community-веса модов с PoE2DB (данные Krakenbul / Prohibited Library,
> патч 0.5.5, снимок 2026-10-03): 53 таблицы по группам баз, 6434 веса. Exalted, Transmutation,
> Augmentation, Regal, Alchemy и Chaos работают там, где у всех кандидатов пула вес известен
> (1180 из 1559 крафтовых баз полностью); если хоть один вес неизвестен — шанс «недоступно», бросок
> отказывает, числа не придумываются. В «Создать предмет» — только реальные базы (без `[DNT]` и
> заготовок уников). Demo (выдуманные тестовые данные) выбирается в шапке.
> [Источники](docs/data-sources.md), [отчёт v0.8](docs/handoff/v0.8-report.md),
> [веса — ADR 012](docs/adr/012-weight-tables.md).

## Запуск

Нужны Node.js ≥ 23 и pnpm 10 (`npm i -g pnpm`).

```bash
pnpm install
pnpm data:art    # локальные картинки (PNG игнорируются git)
pnpm dev          # http://localhost:3000 (адрес 127.0.0.1 разрешён в next.config для dev-ресурсов)
```

Production:

```bash
pnpm build
pnpm start
```

`pnpm build` также подготавливает арт.

Обновление данных после патча:

```bash
pnpm data:refresh        # RePoE fetch → normalize → PoE2DB weights fetch → normalize → validate → weights validate → report
pnpm data:art            # картинки новых баз
pnpm data:golden         # только если эталоны изменились намеренно (проверить diff)
pnpm check
```

По шагам: `pnpm data:fetch` (или `data:fetch:pinned`), `data:normalize`, `data:weights:fetch`
(`-- --refresh` перекачивает страницы PoE2DB), `data:weights:normalize`, `data:validate`,
`data:weights:validate`, `data:report` (покрытие — `data/coverage-report.json`). Веса другой версии
игры набор не примет: сборка падает с подсказкой запустить `pnpm data:weights`.
Цены poe.ninja загружаются через серверный API с кэшем и ручными переопределениями;
`pnpm data:prices "<league>"` сохраняет снимок вне git. Цену базы вводит пользователь.

## Рабочий стол (v0.7)

Первое открытие — пустая сессия: стартовый экран «Импорт предмета» (или просто Ctrl+V) / «Создать
предмет», справа — место цели. Импорт показывает превью (база, редкость, ilvl, префиксы, суффиксы,
fractured) и начинает крафт только по «Начать крафт». Вставка другого предмета во время крафта сначала
спрашивает; цель при этом сохраняется.

```
┌ Исходный: Akoyan Spear · Редкий · ilvl 82 · 3 мода  [Изменить][Сбросить][Импорт] ┐┌ 2 Цель ─────────┐
├ 1 Текущий предмет — верстак: арт, свойства, моды P/S, тир, fractured, ПКМ / «…»   ┤│ требования «N+» │
│   клик валютой = крафт, Ctrl+Z / Ctrl+Shift+Z                                      ││ статусы, прогресс│
├ 3 Инструменты крафта: Валюта | Омены | Эссенции | Катализаторы | Руны · Активный крафт ─────────────────┤
├ 4 Пул модов ───────────────┬ 5 История крафта ──────┬ 6 Затраты и симуляция ────────────────────────────┤
```

| Сущность | Что это | Чем меняется |
|---|---|---|
| **Исходный** (source) | стартовый предмет — строка над текущим | импорт (Ctrl+V / кнопка) или «Создать предмет»; «Изменить исходный» открывает поверхность настройки: база, ilvl, качество, сокеты, стартовые моды, fractured |
| **Текущий** (current) | что получилось сейчас — главный верстак | крафт кликом валютой; ручные правки по ПКМ / «…» (шаг истории, не крафт); Ctrl+Z / Ctrl+Shift+Z, откат к шагу, «Сбросить к исходному» |
| **Цель** (target) | требования к результату — всегда справа | «Собрать цель», «Импорт цели», «Взять текущий как основу» (моды → требования «тир N+»); тир «T1 / T2+…», fractured, удалить |

**Собрать исходный вручную.** «Создать предмет» (или «Изменить исходный» → каталог баз) открывает выбор базы
по шагам (v0.8): тип предмета (броня, бижутерия, одно- / двуручное оружие, вторая рука) → вид (СИЛ,
СИЛ/ИНТ… для брони и щитов, класс для оружия; пропускается, если выбора нет) → база по уровню.
Крошки, «Назад» и Escape возвращают на шаг; «Поиск по всем базам» показывает, где лежит каждая. После выбора настраиваются item level,
качество и сокеты рун — только то, для чего у базы есть правило. Моды добавляются через тот же пул
модов; у каждого мода — тир (недоступные тиры подписаны причиной) и состояние «Обычный / Fractured».
Всё это настройка, а не крафт: валюта не тратится, шаги не пишутся. Качество и сокеты сохраняются в
предмете, но в расчётах пока не участвуют.

**Как крафтить.** Выберите сферу в полосе «Инструменты крафта», при желании Omen во вкладке «Омены», и
наведите курсор на текущий предмет: валюта «повиснет» на курсоре, Omen — кольцевым значком рядом.
Блок «Активный крафт» всегда показывает, что применится, цену клика и шанс цели шага; при смене
валюты Omen остаётся и помечается «несовместимо» или «не смоделировано», если так. Клик применяет её — карточка коротко
вспыхивает, новый мод подсвечивается. Если действие невозможно, на иконке знак запрета и причина
(«Нет свободного суффикса»), а клик ничего не меняет и не стоит. Доступны только смоделированные
инструменты из выбранного набора. Real Data моделирует 9 валют и 8 Omen, но действия,
добавляющие случайный мод, отказывают при неизвестных весах. Остальные 482 расходника
показаны с реальными иконками и помечены «не смоделировано». У Demo отдельные fixture-правила.

**Затраты.** «Потрачено (факт)» — сумма шагов в истории. «Следующий клик» и «Ожидаемо до цели шага» —
оценки. Отменённый шаг вычитается из потраченного; Reset craft возвращает текущий к исходному и
обнуляет историю и потраченное.

**Цель.** По умолчанию — на базе исходного. Если база цели другая, показано «База цели не совпадает с
базой исходного», и шансы к такой цели не считаются. Fractured-требование выполняется только
fractured-модом.

**Пул модов** — один обозреватель на три режима: осмотр пула текущего предмета для активного
инструмента; выбор мода для исходного (по «+ Добавить…» или «Заменить из пула»); выбор требования для
цели. Пул учитывает версию игры, базу, класс и item level исходного.

### Ограничения

- Все числа модов — fixture; каталог — 13 баз трёх классов (копья, луки, посохи), две версии (0.4.0, 0.5.0).
- Качество и сокеты записываются, но не влияют на расчёт; правила их диапазонов не сверены.
- Результат клика — демо-симуляция (мод по весу, значения равномерно), не механика PoE 2.
- Omen работает только как часть смоделированной комбинации, не как отдельный слой.
- Ожидаемая стоимость — оценка шага в модели «повторять из текущего состояния», не маршрута.
- Маршрут до цели не строится; сессия не сохраняется между перезагрузками.

## Структура

```
apps/web                    сайт Next.js (только отображение и композиция)
packages/craft-domain       типы и чистые правила домена
packages/craft-db           версионная база игровых данных + fixture
packages/item-parser        текст предмета → ItemState
packages/probability-engine пул модов, обозреватель пула, вероятности, объяснение
packages/economy            стоимость попытки и этапа
packages/craft-session      демо-применение действий, сессия, сравнение с целью
docs/                       архитектура, модель, инварианты, источники, ADR 001–008
tests/                      архитектурные проверки и проверка картинок (манифест + файлы)
```
